# Postman

Importe [`oficina-saga-microservices.postman_collection.json`](oficina-saga-microservices.postman_collection.json) para exercitar o fluxo integrado (OS, billing e execution).

Variáveis padrão: `baseUrl` 8000, `billingUrl` 8003, `executionUrl` 8002.

Collection legada do monólito (referência): [`oficina-api.postman_collection.json`](oficina-api.postman_collection.json).
